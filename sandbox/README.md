# Sandbox — Safe Experimentation Area

This folder is for learning and experimenting. Nothing here is active or registered
with NanoClaw. Chhagan cannot see or use any of these files.

To make an agent real:
1. Copy its folder into `groups/`
2. Register it via Andy (your WhatsApp main agent) using the `register_group` tool

## Contents

- `example-researcher/` — Example CLAUDE.md for a persistent research agent
- `example-specialist/` — Example CLAUDE.md for a domain specialist agent
- `notes.md` — Your own notes as you experiment
